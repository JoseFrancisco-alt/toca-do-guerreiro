# Toca do Guerreiro · Protótipo

Protótipo **visual** (sem back-end) do agendamento de aula experimental grátis.

- `index.html` — landing Cruzeiro & Santa Lúcia, agendamento em passos, simulação WhatsApp, QR Codes, unidades.
- `custos.html` — proposta em 3 fases + calculadora de custo mensal.

Origem do QR: `index.html?origem=balcao` | `aulao` | `instagram`.

Horários, vagas e endereços são ilustrativos. Nenhuma mensagem é enviada.
